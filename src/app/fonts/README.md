# Local fonts

DM Sans (variable normal, 100–1000) is the interface font. Lora (variable normal and italic, 400–700) is the editorial display font. Both are self-hosted through `next/font/local`, so builds and visitors do not require Google Fonts requests.

Downloaded from the official Google Fonts repository on 2026-09-17:

- https://github.com/google/fonts/tree/main/ofl/dmsans
- https://github.com/google/fonts/tree/main/ofl/lora

The original SIL Open Font License files are included alongside the unmodified font files as `dm-sans-OFL.txt` and `lora-OFL.txt`.
